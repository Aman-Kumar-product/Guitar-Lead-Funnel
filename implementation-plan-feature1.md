# Phase-Wise Implementation Plan: Build Your 5-Song Guitar Setlist

## Phase 1: Data Preparation & Models
**Goal:** Make the 20-song pool available to both the frontend and backend, and update the API schemas.
- **Frontend/Backend Sync:** Convert the `songs_pool.md` into a structured JSON file or a constant array exported in both codebases (e.g., `songsData.js` and `songs_data.py`). This contains `song_name` and `type` (`beginner` or `advance`).
- **Backend API Update:** Modify `backend/models/lead.py` to add a new `selected_songs` field (list of strings) to both `ScoreRequest` and `LeadEmailRequest` pydantic models.

## Phase 2: Backend Logic & Personalization Engine
**Goal:** Implement the logic that generates the personalized copy based on the 5 selected songs and the user's level.
- **Update `result_service.py` (`generate_result`):**
  - Extract the `selected_songs` from the payload.
  - Determine `beginner_count` and `advance_count` from the song pool.
  - Using the user's base level (`is_beginner` flag already returned), inject the appropriate personalization template (Scenarios A through F from the PRD).
  - Append this dynamic paragraph to both the partial result preview (`short_content`) and the full email report (`content`).

## Phase 3: Frontend UI - Setlist Builder
**Goal:** Create the interactive song selection game.
- **Create `SetlistBuilder.jsx` Component:** 
  - Render the 20 song cards in a grid.
  - Manage a selected state array. 
  - Show a visual counter (X / 5 selected).
  - Enforce exactly 5 selections. 
  - Show a "Build My Guitar Roadmap →" CTA when exactly 5 songs are selected.
- **Integrate into `Funnel.jsx`:** 
  - Insert `SetlistBuilder` between the final questionnaire step and the `GatedResult` view.
  - Store the `selected_songs` in the Funnel's state.

## Phase 4: Frontend GatedResult & API Integration
**Goal:** Send the newly collected data to the backend and display the customized partial preview.
- **Update `GatedResult.jsx`:**
  - Pass the `selected_songs` in the payload for both the partial preview (`/api/score`) and full email unlock (`/api/lead`).
  - The `partialResult` displayed will now automatically include the new paragraph generated by the backend!

## Phase 5: Email Template Updates
**Goal:** Ensure the final email visibly highlights their 5-song roadmap.
- **Update `email_service.py` (`send_result_email`):**
  - Inject the 5-song list into the email body, under a new `## 🎸 Your 5-Song Guitar Goal` heading.
  - The customized roadmap text (which includes the new paragraph) will be seamlessly displayed as part of the `result_content`.
